# Shinobi Idle — MVP: зріз і баланс

Дані зрізу MVP, готові до імпорту в гру, і модель балансу. Зібрано 14.11.2026.

| Файл | Що це |
| --- | --- |
| `patch.mjs` | Усі рішення щодо складу зрізу: приховані, змінені й додані техніки, рецепти, пули, практики, місії, мапа, вороги, боси, будівлі, спорядження, реєстр печаток і послідовності |
| `build_slice.mjs` | Бере заморожену карту навичок (`../Shinobi Idle — дані й скрипти/concept/map_data_v3.json`) і `patch.mjs`, пише `slice.json` і `audit.md` |
| `slice.json` | Повний склад зрізу: джерело для імпорту на етапі 0 |
| `audit.md` | Перевірка замкненості: розриви рівнів, атаки, ранги, предмети, риси, трійки природ, мапа, посилання за межі зрізу |
| `balance.mjs` | Модель балансу: параметри `K`, формули, спрощений симулятор бою, розрахунок темпу |
| `balance.json` | Параметри й обчислені числа технік, ворогів, місій |
| `balance_tables.md` | Ті самі числа таблицями: 11 розділів |

Перебудова (потрібен лише Node.js):

```bash
node build_slice.mjs
```

```bash
node balance.mjs
```

Пояснення рішень — у документах `../Shinobi Idle — MVP — правки зрізу.md`, `../Shinobi Idle — модель балансу.md`, `../Shinobi Idle — сюжет усієї гри.md`.
