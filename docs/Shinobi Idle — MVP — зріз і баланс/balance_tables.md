## 3. Техніки зрізу

## 4. Стани, комбо, звикання

| Стан | Ефект |
| --- | --- |
| Горіння | 30% шкоди техніки додатково за 6 с; на цей час зупиняє Регенерацію |
| Мокрий | Ворог діє на 15% повільніше, 8 с |
| Оглушення | Ворог пропускає 0.7/1/1.5 с (ранг D/C/B) і втрачає каст |
| Сковування | 3.68 с: ухилення ворога ×0,3; риса «Ухильний» не діє |
| Отруєння | 2% максимального HP за секунду, 8 с |

Шанс комбо = 15% + 0.4% × рівень стихії + 0.1% × Майстерність, не більше 60%.

| Комбо | Ефект |
| --- | --- |
| Футон по Горінню | Горіння ×1.5 і тривалість заново |
| Райтон по Мокрому | Оглушення ×2 |
| Дотон по Мокрому | Сковування 3.68 с, ухилення ×0.5 |
| Катон по Мокрому | Знімає Мокрий, разова шкода 40% від шкоди техніки |

Звикання: −15% за кожен повтор техніки проти того самого ворога, до −60%; для коронної — удвічі повільніше. Колесо природ: ±30% шкоди.
