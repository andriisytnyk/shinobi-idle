# Shinobi Idle — MVP — ручне тестування

Пам'ятка для першого проходження зрізу вручну: як запустити збірку, як рухатися швидше й на що дивитися.

## Запуск

Усе з кореня репозиторію.

1. Гілка для перевірки — `test`: `git checkout test`, потім `git pull`.
2. `pnpm install`.
3. Один зі способів:
   - **Режим розробки** (зміни підхоплюються одразу): `pnpm dev`, далі `http://localhost:5173/?dev=1`.
   - **Тестова збірка** (як у гравця, з панеллю розробника): `pnpm --filter web build:test`, потім `pnpm --filter web preview`; адреса — у виводі команди, додай `?dev=1`.

Гра відкривається лише в одній вкладці: друга вкладка попросить перейти в неї.

Нова гра на чистому збереженні: панель розробника → «Нова гра» або інша адреса (наприклад, `127.0.0.1` замість `localhost`): збереження окремі для кожної адреси.

## Панель розробника

Кнопка «Панель розробника» з'являється з `?dev=1` лише в режимі розробки й тестовій збірці; у фінальній збірці її немає.

- **Час:** швидкість ×1 / ×2 / ×5 / ×10 або своя; кнопки «перемотати» на хвилини й години — так перевіряється звіт офлайну.
- **Навички й Майстерність:** задати рівень навички, Майстерність техніки чи дії.
- **Речі й валюта:** видати будь-яку річ, рьо, Intel; вивчити техніку; прочитати сувій.
- **Сюжет:** завершити поточний крок ланцюжка, поставити чи зняти прапор, відкрити ранг або іспит.
- **Мапа:** розвідати всі гекси, відкрити всі точки, перенести персонажа чи клона на гекс.
- **Бої:** рівень Бінго-книги ворога, перемога чи поразка в поточному бою, набіг зараз.
- **Клони:** створити клона з заданим життям і запасом, змінити або поповнити життя, розвіяти, зняти втому розуму.
- **Збереження:** показати й завантажити текст збереження, готові збереження для різних етапів, нова гра (поточна стає резервною копією). Експорт файлом — у налаштуваннях.

Порада: перше проходження — без панелі хоча б до Геніна (≈ 1 год), щоб відчути темп; далі прискорення ×5–×10.

## На що дивитися

Цілі темпу з «правок зрізу» (розділ 6, рядок 9): Генін ≈ 1 год, Чунін за 20–50 год; найдовший відрізок без нового — не більше 15–20% часу гри й не більше 6–8 год; жодна навичка на Чуніні не нижча за 20.

1. **Перша година.** Академія, підказки, іспит на Геніна, вибір природи. Чи зрозуміло, що робити далі.
2. **Клони.** Створення з запасом, панель «Загін» (на телефоні — смужка над навігацією), кнопка «Почати» з вибором виконавця, діалог розсіювання (знання, торба, втома розуму), життя від чакри.
3. **Бій.** Екран підготовки з прогнозом, бойові тіньові клони як союзники, ролі клонів («Як ти», «Натиск», «Підтримка», «Відволікання»), журнал бою, кілька боїв одночасно (перемикач).
4. **Мапа.** Розвідка гексів (5 с), точки інтересу, місця сили (бонус лише тому, хто стоїть), переходи, пошук у руїнах фортеці й збір сірки в Пекельній долині (сторінка Розвідки або сторінка роботи з точки на мапі).
5. **Сюжет і ранги.** Доручення, «Сірі пов'язки», операція «Сховок у Долині», звання за Репутацію, іспит на Чуніна.
6. **Офлайн.** Закрий гру або перемотай години: звіт про час відсутності (досвід, речі, валюта, клони, набіги).
7. **Телефон.** Те саме на ширині телефону або на справжньому телефоні; встановлення як застосунку (PWA).

## Рішення, які варто оцінити під час гри

| Що | Де | Варіанти |
| --- | --- | --- |
| Множник бойових клонів | бій із бойовими клонами | зараз бойовий досвід за годину зростає в середньому в 3,6 раза, до 15,9 у ботів; лишити чи обмежити (#140) |
| Мирний шлях | гра без боїв | чи мають цілі темпу діяти й для гравця, що не воює (#140) |
| Операція «Сховок у Долині» | «Сірі пов'язки», крок 8 | зі свіжими силами вигравання ≈ 14%: поповнення між етапами, інший порядок етапів чи лишити (#82) |
| Збір сірки | Пекельна долина | сірка — рідкісна здобич (≈ 2,7 за год): чи не здається дія порожньою (#149) |
| Кнопка «Почати» | будь-яка дія з клонами | обирає того, хто вже робить цю дію; чи краще першого вільного клона (#132) |
| Миттєвий перехід | мапа, переходи за рьо чи через заставу | зараз зупиняє поточну дію; чи має дія, що не залежить від місця, тривати (#104) |
