# Мапа для художника

Матеріали, щоб замовити мальовану мапу світу: малюнок ляже під гексову сітку гри, як мапа в Картографії Melvor. Підготовлено 18.11.2026.

| Файл | Що це |
| --- | --- |
| `artist-brief.md` | Бриф для художника: що малювати, вигляд кожної країни, таблиці точок інтересу (номер, назва, канон чи вигадане, що шукати, що малювати, референси), рельєф кожного гекса зрізу MVP |
| `map-pois-3840x2139.png` | Контрастна мапа з номерами всіх 165 точок інтересу: чорні — з мапи автора (точне місце), сині — місця зрізу MVP, зелені — нові канонічні, помаранчеві — нові вигадані. Номер у кружечку = номер у брифі |
| `map-template-3840x2139.png` | Шаблон для малювання: точна сітка гри, кольори країн, море, межі, координати гексів |
| `map-grid-overlay-3840x2139.png` | Лише сітка на прозорому тлі — накласти на готовий малюнок і перевірити, чи все стало на місце |
| `world-pois.json` | Ті самі точки в машинному вигляді (гекс, країна, походження, вид точки в грі) — знадобиться, коли точки поза зрізом стануть даними гри |
| `генератор/` | Скрипти, що будують усе це, і копії вхідних даних мапи на 18.11 |

**Що перевірити перед передачею художнику.** Канонічні місця, розташування яких канон не фіксує (гора Мьобоку, ліс Шіккоцу, печера Рюучі, Кусаґакуре, сховок Сасорі, замок Хозукі), стоять там, де правдоподібно, — їх можна пересунути. Руїни Узушіо стоять у Країні Хвиль, бо на мапі автора вона — колишня Країна Водоворотів. Референси з реального світу вписано з пам'яті — варто проглянути.

**Як змінити точку й перемалювати.** Точки лежать у `генератор/pois-data-new.mjs` (нові) і `pois-data-existing.mjs` (з мапи автора й зрізу). Після зміни з теки `генератор`:

```bash
node build-pois.mjs
node build-brief.mjs
node make-template.mjs 2
```

Нові файли з'являться в `генератор/`; скопіюй їх на місце цих. Для PNG потрібні встановлені залежності репозиторію (`pnpm install`).

Зображення-орієнтир автора (мапа світу з мережі) сюди не входить і в репозиторій не потрапляє.
