# Shinobi Idle — дані й скрипти

Робочі джерела, з яких зібрано концепт v3 і карту навичок v3. Знадобляться для реалізації MVP: дані гри варто генерувати з тих самих джерел, що й карту.

| Папка | Що там |
| --- | --- |
| build/v3_data.js | Місії (39), вимоги технік (42), пік навичок, мережа потреб, регіони (17), сенсеї, спорядження, джерела й витрати рьо |
| build/tech.txt | Таблиця технік: рівень, назва, ранг, роль, теги, стан, джерело, домівка, вимога, нотатка |
| build/build_map*.js, patch_v3.py | Збирання карти навичок: build_map.js — база v2, patch_v3.py робить з нього build_map_v3.js |
| build/rebuild_all.sh | Повна перебудова: карта, фрагменти, концепт, рішення MVP |
| concept/ | Концепт v2 (concept.md), блоки й фрагменти версії 3, edit_concept.py і patch_mvp_story.py; map_data_v3.json — зібрані дані карти |
| tools/ | Валідатори карти (jsdom); npm install перед запуском |
| research/ | Канонічні техніки: зібраний перелік і зведення |

Порядок перебудови: `bash build/rebuild_all.sh`. Скрипти розраховані на шляхи робочої сесії (/home/claude/work/...), тож у новому середовищі шляхи треба поправити. На вхід build_map_v3.js іде оригінальна карта v1 (HTML), яку ти завантажував на початку.
